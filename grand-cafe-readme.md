# Grand Cafe UK

A professional, responsive one-page website concept created from the supplied Grand Cafe UK Google Maps listing data.

## GitHub Pages
Enable GitHub Pages for this repository with the `main` branch as the deployment source, then open:
`https://vincentplaza.github.io/vincentplaza-portfolio/grand-cafe.html`

## Included
- Responsive mobile/desktop layout
- Hero, about, menu highlights, reviews, visit/contact sections
- Click-to-call phone link
- Google Maps directions link
- Accessible semantic HTML and responsive CSS

Business details are based only on the information supplied in the brief and should be verified by the cafe before publication.
